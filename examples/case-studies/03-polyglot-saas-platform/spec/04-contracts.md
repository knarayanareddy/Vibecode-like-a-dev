## 3. Conventions that bind you

Only the conventions this profile makes load-bearing are listed. The selected-practice table in 00-constitution.md names every additional obligation this packet actually selected; no unselected library practice is implied.

| Concern | Rule |
| --- | --- |
| Identifiers | Every analytics id is opaque and sortable (ULID); a sequential integer never appears in an external shape, because it invites enumeration. |
| Timestamps | Instants on an analytics are ISO-8601 UTC with `Z`; a local time or a bare date is a bug, not a style choice. |
| Tenant | Derived from the authenticated session, never from a body field or a query parameter. |
| Errors | One envelope for every failure — including an unknown route and a rejected analytics — and an absent field is absent, not `null`. |

## 4. Error envelope

One shape for every failure. A caller must be able to handle an unknown route with the same code as a rejected input.

```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "The analytics is not in a state that allows this.",
    "correlationId": "01J8Z9W3Q4K5M6N7P8R9S0T1V2",
    "details": [
      {
        "field": "analytics",
        "reason": "conflict"
      }
    ]
  }
}
```

| Status | Meaning | When |
| --- | --- | --- |
| 401 | No valid session | Missing, expired or revoked credential. No analytics is created and no state changes. |
| 403 | Authenticated but not permitted | Policy denied for this tenant. Never reveal whether the analytics exists. |
| 404 | Not found, or not visible to this actor | One response for both cases, so an analytics id cannot be used to probe. |
| 409 | Conflict with current state | The analytics would be left in a state `02-domain-model.md` calls illegal, or a replay carries a different payload. |
| 422 | Semantically invalid | Well-formed but breaks a rule that makes an analytics valid. |

## 5. Contract tests

- Each of the 5 surfaces gets one test for its success shape and one for the analytics failure it is most likely to hit.
- Anything this product consumes is tested against a recorded response; a hand-written mock of a tenant drifts silently.
- Changing a shape in section 2 fails the build before review, because the test that pins it lives beside the analytics it serialises.

Before implementing any row above: shape written, error code chosen, one failure example recorded.
