### Naming rules

- One spelling per concept, used verbatim in code, tests and commit messages: if the table says `board`, nothing calls it a "board" or a "record".
- A qualifier ("board v2", "user board") means two concepts, or a badly named one.

## 2. Bounded contexts

| Context | Owns | Talks to | Notes |
| --- | --- | --- | --- |
| Core | the product's central aggregate (name it) | every other context | Owns the rules that make this product itself. No framework or vendor imports. |
| Identity & Access | Account, Session, Policy, Membership | Core | Authenticates and authorises; other contexts receive an actor, never a password. |
| Realtime | Channel, Subscription | Core | Fan-out only; never the source of truth for domain state. |

A context exposes behaviour through an interface it owns and never reaches into another context's tables; with 3 contexts here, the only cross-context traffic allowed is a declared call or an event. That rule is what makes modular monolith with enforced boundaries a description rather than a hope.

## 3. Aggregates and catalog invariants

Each invariant is a claim a test can make false. These come from the requirements you selected; the remaining 1 aggregates are in `spec.json`.

### Record `(REQ-004)`

- Every record has a stable identity that never changes.
- Deleted records are soft-deleted only if a retention rule allows it.

### Account `(REQ-005)`

- An account has exactly one active credential set at a time.
- A revoked session can never be un-revoked; a new session is issued instead.

### Session `(REQ-005)`

- A session has an absolute expiry that cannot be extended by activity indefinitely.
- A session token is verified server-side before any state change.


## 4. State machines


**Session:** `issued → active → expired`, and `active → revoked` at any time. `revoked` is terminal.


Any other state machine around a board: write the states, the legal transitions and the illegal ones as a table before implementing. An illegal transition returns a typed error, never a silent no-op.

## 5. Domain events

| Event | Emitted when | Consumers |
| --- | --- | --- |
| SessionRevoked `(REQ-005)` | When a session is revoked for any reason. | Audit, cache eviction |

Events carry the board id and are named in the past tense; a consumer must survive the same event twice and an event that arrives after the next one.

## 6. Rules for domain code

- Nothing under the domain directory imports the web framework, PostgreSQL + Drizzle (forward-only SQL migrations), or a vendor SDK; the import-boundary rule in `03-architecture.md` checks it.
- Time and randomness are passed in, so a test can pin the moment a board changes state.
- Dates are UTC instants; local time is presentation and belongs to the transport layer.
