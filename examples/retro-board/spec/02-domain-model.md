### Naming rules

- A term is used verbatim in code, tests, commit messages and UI copy. No synonyms.
- "User" is a UI word, not a domain word: code uses the actor type this table names.
- If a concept needs a qualifier ("payment v2", "user record"), it is two concepts or a badly named one.

## 2. Bounded contexts

| Context | Owns | Talks to | Notes |
| --- | --- | --- | --- |
| Core | the product's central aggregate (name it) | every other context | Owns the rules that make this product itself. No framework or vendor imports. |
| Identity & Access | Account, Session, Policy, Membership | Core | Authenticates and authorises; other contexts receive an actor, never a password. |
| Realtime | Channel, Subscription | Core | Fan-out only; never the source of truth for domain state. |

- A context exposes behaviour through an interface it owns; it never reaches into another context's tables.
- Cross-context communication is a declared call or an event. Never a shared table.

## 3. Aggregates and invariants

Each invariant is a claim a test can make false. If you cannot write the failing test, the invariant is not yet understood.

### Record `(REQ-004)`

- Every record has a stable identity that never changes.
- Deleted records are soft-deleted only if a retention rule allows it.

### Account `(REQ-005)`

- An account has exactly one active credential set at a time.
- A revoked session can never be un-revoked; a new session is issued instead.

### Session `(REQ-005)`

- A session has an absolute expiry that cannot be extended by activity indefinitely.
- A session token is verified server-side before any state change.

### Policy `(REQ-006)`

- Deny is the default when no policy matches.
- A policy decision never depends on client-supplied roles.


## 4. State machines


**Session:** `issued → active → expired`, and `active → revoked` at any time. `revoked` is terminal.


Any other state machine: write the states, the legal transitions and the illegal ones as a table before implementing. Illegal transitions return a typed error, never a silent no-op.

## 5. Domain events

| Event | Emitted when | Consumers |
| --- | --- | --- |
| SessionRevoked `(REQ-005)` | When a session is revoked for any reason. | Audit, cache eviction |

Events are named in the past tense. A consumer must behave correctly when the same event arrives twice and when it arrives late.

## 6. Rules for domain code

- No imports from the web framework, the database driver, the queue client or any vendor SDK.
- Pure functions and explicit inputs: time and randomness are passed in, not read from the environment.
- Errors are typed domain errors; no error strings compared in tests.
- Money is integer minor units with a currency. Dates are UTC instants; local time is presentation.
