**Status:** Complete — local and hosted validation passed.

## Goal

Close the newly confirmed cross-surface defects without weakening VLD's deterministic, local-only authority boundaries. Every fix must include a regression that executes the affected public or generated surface—not only a unit test of a helper.

## Review corrections retained as scope boundaries

- Runtime receipt replay/idempotency APIs already inspect the complete ledger. The defect is the use of the bounded status projection for lifecycle authority and the replay validator's bounded duplicate detection.
- The adopted remote name can escape its temporary root to the parent, but the existing tail parser does not directly select arbitrary sibling names. Fix containment rather than relying on that incidental limitation.
- The generated gate runner's placeholder allowlist is narrow, but its line-wide exemption remains unsafe.
- `verify.mjs` now skips symlinks. Remaining symlink work is bootstrap/adoption writes and dangling-link detection in project policy paths.
- `npm run check` already includes evaluation and stress suites. It must still cover the Studio extension test to become the documented deterministic local gate.
